

# NFL Field Goal Performance Analysis

This project analyzes Dallas Cowboys kicker Brandon Aubrey's field-goal performance using R.

## Project Overview
I compared Aubrey's 2025 field-goal percentage with his reported career percentage to determine whether there was a statistically significant difference.

## Tools and Methods
- R and RStudio
- Quarto
- ggplot2 for data visualization
- Exact binomial hypothesis testing
- 95% confidence intervals

## Results
Aubrey made 85.7% of his field goals in 2025, compared with a reported career percentage of 88.2%. The hypothesis test did not find a statistically significant difference (p = 0.6294).
